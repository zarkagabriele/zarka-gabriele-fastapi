## L'ambiente di lavoro

Domanda 1 (Cos'è un codespace, dove gira e cosa serve):
È un ambiente di sviluppo completo (un computer Linux con VS Code) che gira nel cloud sui server di GitHub invece che sul tuo PC.

Domanda 2 (A cosa serve .venv e perché non va su GitHub):
È una cartella isolata che contiene solo le librerie Python (con le loro versioni esatte) necessarie a questo specifico progetto, evitando conflitti con altri programmi.

Domanda 3 (Differenza tra Commit e Sync Changes):
Il Commit salva una "fotografia" locale delle modifiche fatte ai file nel tuo codespace, accompagnata da un messaggio descrittivo. Sync Changes invia effettivamente queste fotografie salvate dal codespace al repository online su GitHub, rendendole permanenti e visibili.
